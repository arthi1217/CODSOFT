# 🚀 CODSOFT Machine Learning Internship

This repository contains all the tasks completed as part of my Machine Learning Internship at CodSoft.  
These projects helped me gain hands-on experience in data preprocessing, feature engineering, and building machine learning models.

---

## 📌 Tasks Completed

### 🔹 Task 1: Spam SMS Detection
- Built a model to classify SMS messages as spam or not spam
- Used TF-IDF for text vectorization
- Applied Naive Bayes algorithm
- Achieved ~95% accuracy

---

### 🔹 Task 2: Movie Genre Classification
- Predicted movie genres based on plot summaries
- Used TF-IDF for feature extraction
- Applied machine learning models for classification
- Achieved ~44% accuracy

---

### 🔹 Task 3: Customer Churn Prediction
- Predicted whether a customer will leave a service
- Used customer data and behavior features
- Applied Logistic Regression model
- Achieved ~80% accuracy

---

### 🔹 Task 4: Credit Card Fraud Detection
- Detected fraudulent transactions from financial data
- Performed data preprocessing and feature encoding
- Applied Logistic Regression model
- Achieved ~99% accuracy
